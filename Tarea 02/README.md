# Proyecto Final: Análisis de Texto sobre Violencia contra las Mujeres

🎯 Objetivo:

Evaluar el conocimiento adquirido sobre técnicas de procesamiento de lenguaje natural (PLN), minería de texto y modelos de lenguaje, mediante el análisis temático de un conjunto de noticias reales sobre violencia contra las mujeres.

📄 Instrucciones Generales
	1.	Descarga el dataset desde: https://zenodo.org/records/6958808
	2.	Elige una o más técnicas vistas en clase:
	•	Preprocesamiento de texto
	•	Extracción de palabras clave
	•	Clasificación de textos
	•	Análisis de sentimientos
	•	Embeddings y visualización semántica
	•	BERT o modelos de lenguaje
	3.	Documenta todas tus decisiones, técnicas y resultados en un reporte estructurado.
	4.	Entrega tu código, visualizaciones y el reporte en formato PDF o notebook.

📋 Actividades Requeridas

1. Carga y exploración de datos
	•	Descargar y leer el archivo.
	•	Mostrar ejemplos de títulos y cuerpos de noticia.
	•	Verificar y corregir posibles problemas de codificación, duplicados o textos vacíos.

2. Preprocesamiento
	•	Normalización (minúsculas, eliminación de puntuación, acentos).
	•	Tokenización.
	•	Eliminación de stopwords.
	•	Lemmatización o stemming.

3. Análisis temático (elige una o varias opciones)
- Análisis de sentimientos
	•	Aplicar un modelo preentrenado (TextBlob, VADER, BERT).
	•	Comparar resultados entre noticias.

- Clasificación automática
	•	Crear etiquetas (ej. noticias que mencionan feminicidio, abuso psicológico, etc.).
	•	Entrenar un clasificador (Naive Bayes, SVM, o transformer) con validación.

- Representación vectorial
	•	Obtener embeddings (TF-IDF, Word2Vec, BERT).
	•	Visualizar con PCA o t-SNE.

🧾 Estructura del Reporte

1. Introducción
	•	Contexto social del problema.
	•	Justificación del análisis.

2. Descripción de los datos
	•	Estructura del dataset.
	•	Estadísticas básicas.

3. Metodología
	•	Técnicas aplicadas (preprocesamiento, modelos).
	•	Justificación de cada elección.

4. Resultados
	•	Tablas y gráficos.
	•	Interpretación de temas o emociones detectadas.

5. Discusión
	•	Análisis crítico de los hallazgos.
	•	Limitaciones y recomendaciones.

6. Conclusiones
	•	Contribuciones del análisis.
	•	Posibles usos en políticas públicas, ONGs, medios, etc.
